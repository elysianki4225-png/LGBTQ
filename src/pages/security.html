这个网站没有账号、没有评论、没有统计脚本、没有第三方字体，也不要求你填写任何个人信息。但“本站不收集数据”不等于“你绝对安全”：你的网络服务商、浏览器、所在网络、访问的托管平台与点击的外链，都可能留下记录。本页把本站的做法、你的风险与可采取的防护讲清楚，不夸大，也不吓人。

本站的承诺

不设账号、不收集表单、不读取剪贴板、不调用摄像头/麦克风/定位、不加载第三方脚本、不使用统计或广告、不做指纹识别、不写入 Cookie。主题偏好只保存在你浏览器的 localStorage 中，可随时清除。所有搜索与筛选都在本地完成。

即使本站不收集，什么仍然可见

“本站不收集”只描述本站的行为。以下信息仍可能被他人看到：

  • 你的 IP 与访问时间： GitHub Pages 及其 CDN 会处理请求；网络服务商、公司/学校网关与公共 Wi-Fi 也可能记录。
  • 浏览器与设备信息： 任何 HTTP 请求都会附带 User-Agent、语言与部分能力信息。
  • DNS 查询： 你的 DNS 解析服务商知道你访问了哪个域名。
  • URL 路径： 例如访问 /china/ 或 /health/，可能在网关、代理或浏览器历史中留痕。
  • 外链目标： 点击后，对方站点会收到请求；部分站点会设置 Cookie 或要求登录。
  • 本地设备： 共用电脑的浏览历史、下载记录与 localStorage 可能被他人看到。
  • 截图与转发： 一旦你截图或转发，本站无法控制其传播。

这些风险不是本页能消除的；它们取决于你的设备、网络与对手。下一节给出可操作的对策。

先想清楚：你在防谁

同事/同学/家人

风险来自共用设备、浏览器历史、通知栏与屏幕可见性。对策：隐私模式、独立浏览器配置、关闭通知、离开时锁屏、不要把本站加入共享书签。

雇主/学校网络

网关可能记录域名与 SNI，甚至做 TLS 检查。对策：使用可信 VPN/Tor、避免在工作设备上访问、使用 HTTPS 并注意证书警告。

平台与广告商

即使本站不跟踪，浏览器指纹、扩展与运营商仍可能跨站关联。对策：减少扩展、使用隐私浏览器、定期清理、避免登录同一账号浏览敏感内容。

国家/地区级监控

高风险环境下，访问本身可能被记录。对策：评估法律风险、使用 Tor 或可信工具、避免在敏感时期集中访问、不要在境内账号上分享链接。本站无法提供规避国家监控的保证。

可操作的防护

  1. 使用隐私模式或独立浏览器配置。 这不隐藏 IP，但可减少本地历史、Cookie 与自动填充的残留。
  2. 不要在共用设备上保存书签或密码。 使用后清理历史、下载与截图；关闭“继续上次会话”。
  3. 考虑 Tor 或可信 VPN。 Tor 隐藏目标站点对你的 IP 的可见性，但可能被网络封锁；VPN 的信任取决于运营商。没有一种工具适合所有威胁模型。
  4. 使用 HTTPS 并检查证书。 本站通过 GitHub Pages 提供 HTTPS；若出现证书警告，不要继续输入任何信息。
  5. 不要把敏感信息发给任何人。 本站没有表单，也不会索要身份证、病历、裸照或验证码。任何自称本站的索取都是诈骗。
  6. 外链先复制、后打开。 若担心来源页泄露，可复制链接到新窗口或隔离环境；不要在陌生站点登录同一账号。
  7. 关闭通知与预览。 锁屏通知、消息预览与云同步可能暴露你访问的内容。
  8. 定期清理 localStorage。 在浏览器设置中清除本站数据即可删除主题偏好；它不含身份信息。

快速离开

页面右上角提供“快速离开”按钮：点击后立即跳转到中性的搜索页，并用当前页面替换历史记录，使“后退”不回到本站。它不是万能的：浏览器历史、DNS 缓存、网关日志与截图仍可能存在。若你处于紧急危险，先离开现场、联系可信任的人或拨打 110，而不是只依赖网页按钮。

你也可以使用键盘快捷键：Esc 关闭移动导航；部分浏览器支持 Ctrl/Cmd + W 关闭标签页。若使用共用电脑，关闭前清理历史与下载记录。

自托管时的隐私

如果你按部署页把本站放到自己的服务器，隐私取决于你的配置：服务器访问日志、CDN、反向代理与 TLS 证书都会产生记录。建议：关闭不必要的访问日志或缩短保留期、不接入第三方分析、使用自签或 Let's Encrypt 证书、限制目录列表、定期更新。你可以在 deploy/ 中查看示例配置，并按自己的威胁模型调整。

  • 不能保证你的网络服务商、雇主、学校或政府看不到你访问本站。
  • 不能保证 GitHub Pages 或任何托管平台不记录请求。
  • 不能保证外链安全、内容准确或隐私政策友好。
  • 不能替代专业的安全审计、法律意见或危机干预。
  • 不能防止你自行披露信息、截图或被他人识别。

我们能做的是：不主动收集、不加载第三方、不用暗黑模式、把数据流讲清楚。剩下的，需要你根据自己的环境判断。
