光谱档案（Spectrum Archive）是一个非官方、非营利的社区资料项目。它不隶属于任何政党、宗教、国家机构或商业公司，也不接受广告或赞助。它想做的事很简单：把散落的中文资料整理成一份可读、可核查、对隐私友好的档案，让正在寻找答案的人少走一点弯路。

AI 构建声明

本项目的代码与大部分文字由 AI 辅助生成，再由维护者整理、校对与修订。AI 会犯错：可能引用不存在的来源、混淆时间线、把争议写成定论。我们尽量用可核查的链接、日期与限定语来降低风险，但不能保证内容完全无误。请把本站当作研究起点，而不是最终裁决；涉及医疗、法律与安全决定时，务必咨询有资质的专业人士。

为什么做这个站

中文互联网上关于 LGBTQ+ 的信息并不少，但常常碎片化、过期、带有强烈立场，或在平台清理后消失。一个正在探索身份的人，可能要在搜索结果、短视频、匿名帖与营销号之间拼凑答案；一个想支持孩子的家长，可能先看到的是“矫正”广告；一个跨性别者想查证件流程，可能找到的是几年前的帖子。

我们想提供一个稳定的、可以慢慢读的地方：不要求登录，不弹窗，不追踪，不用 emoji 代替思考，也不把任何一个国家或群体当作笑话。内容覆盖全部性少数身份，重点补充中国语境下的医疗、法律、家庭与社群现实，同时呈现国际比较与不同立场的争论。

编辑原则

事实优先，但承认不确定

能核实的事实给出处与日期；仍在争议的，说明双方理由；不知道的，写“不知道”。不用“显然”“众所周知”掩盖证据不足。

不替任何国家或政党站台

我们批评具体的法律、政策与做法，也记录进步与复杂性；不用“文明 vs 落后”的框架给国家排队，也不把批评等同于否定一个社会。

自称优先

一个人如何称呼自己，优先于我们的词表。我们不替群体规定“正确”的身份，也不把某种 transition 路径当作标准答案。

不猎奇，不消费痛苦

不放手术细节的猎奇描写，不把自杀当作浪漫，不用个别案例概括整个群体。涉及暴力与创伤时，优先考虑当事人的安全与同意。

隐私是设计的一部分

不收集、不追踪、不加载第三方脚本；搜索在本地完成；不要求账号。我们宁可少一些功能，也不把访问者变成数据。

可持续，而不是一次性

内容标注更新日期，来源可追溯，代码可自托管。欢迎更正；错误会被记录与修正，而不是悄悄删除。

AI 参与方式与人工校对

本项目的初始代码、样式、构建脚本与页面草稿由 AI 生成，维护者负责设定结构、选择来源、修订措辞与检查事实。AI 的典型错误包括：编造看似合理的引用、把不同年份的事件混在一起、把某一国的规则写成“国际标准”、在敏感议题上过度概括。我们采取以下措施：

  • 优先引用官方文件、法院判决、同行评议研究与主要人权组织；对二手报道标注“据报道”。
  • 在争议议题上同时呈现支持与批评的理由，并标明哪些是事实、哪些是观点。
  • 给数字加上样本、年份与局限；不把社群便利样本当作全国人口数据。
  • 标注更新日期；法律与医疗信息特别容易过期。
  • 欢迎读者指出错误；更正时保留说明，而不是悄悄改写。

如果你发现事实错误、过时信息、冒犯性措辞或缺失的来源，请通过仓库的 Issue 提交，并附上可核查的链接。我们不会因为“立场不同”删除评论，但会拒绝仇恨、骚扰与未经同意的个人信息。

技术栈与设计

构建

零依赖 Node.js 脚本：读取 src/site.config.mjs、页面片段与模板，输出静态 HTML、站点地图、robots 与本地搜索索引。没有框架、没有运行时依赖、没有构建缓存。

样式

Material Design 3 风格的 CSS 变量（颜色、排版、形状、阴影、动效），支持浅色/深色/跟随系统，响应式布局，prefers-reduced-motion 与 forced-colors 适配。

交互

原生 JavaScript：主题切换、导航抽屉、快速离开、复制、词汇表筛选与站内搜索。所有监听器挂在同一个 AbortController 上，页面离开时统一移除；无 setInterval、无 WebSocket、无第三方脚本。

图标

内联 SVG symbol sprite，不使用 emoji 作为界面图标；图标带 aria-hidden，可交互控件有文字标签与焦点样式。

隐私

无 Cookie、无分析、无表单、无第三方字体；CSP 限制资源来源；搜索索引静态加载，查询不上传。详见安全页。

部署

GitHub Pages 自动发布；VPS 提供一键脚本，支持 Let's Encrypt、自有证书与 nip.io。详见部署页。

可访问性

  • 语义化 HTML：landmark、标题层级、表格 caption、表单 label。
  • 键盘可达：跳过链接、可见焦点、抽屉可用 Escape 关闭。
  • 颜色对比：正文与背景达到 WCAG AA；不仅用颜色传达状态。
  • 动效：尊重 prefers-reduced-motion，不播放自动动画。
  • 屏幕阅读器：图标装饰性隐藏、状态变化用 aria-live 播报。
  • 打印：提供打印样式，隐藏导航与交互元素。

我们仍在学习。如果你使用辅助技术遇到障碍，欢迎告诉我们具体页面与操作步骤。
