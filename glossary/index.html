语言与定义

词是工具，不是判决。

同一词在不同社群、语言与年代里可能有不同含义。本页给出常见中文与英文术语的工作定义、使用提示和争议说明；当一个人告诉你 ta 希望被怎样称呼时，那比词典更重要。

语言会变，而且变的速度往往快过字典。一个词在 2010 年是尊重的说法，到了 2026 年可能已经被社群视为过时；一个英文词翻译成中文，也可能失去原有的语境。本页不是“标准答案”，而是一份可讨论的词表：给出常见用法、争议与替代说法，并提醒你——当一个人告诉你 ta 希望被怎么称呼时，那比任何词条都优先。

三条使用原则

自称优先： 一个人如何称呼自己，优先于通用定义。语境优先： 同一个词在医学、法律、社群与媒体中的含义可能不同。不猎奇： 不要用术语去追问别人的身体、性生活或病历。

词表

LGBTQ+

女同性恋（Lesbian）、男同性恋（Gay）、双性恋（Bisexual）、跨性别（Transgender）、酷儿/疑问中（Queer/Questioning）的缩写；“+”表示其他性少数与性别多元身份。它是一个政治与社群联盟标签，不是对所有个体的精确描述。有人更喜欢“ queer ”“性少数”“同志”或具体身份词。

性少数

中文语境中对性倾向、性别认同或性别表达不属于多数群体的统称。它比“LGBT”更宽，也更本土；但“少数”一词可能暗示数量与边缘地位，部分人更喜欢具体身份名称。

性倾向 / 性取向

一个人在情感、浪漫与性方面被谁吸引。常见类别包括异性恋、同性恋、双性恋、泛性恋、无性恋等。性倾向与性别认同是不同维度：跨性别者的性倾向可以是任何一类。

性别认同

一个人内在对自己性别的感受与认知，可能为女性、男性、非二元、流动或其他。它不是由出生时的指派性别、外貌或性倾向决定的。

指派性别

出生时基于外生殖器、染色体或其他特征被登记的性别。常用“出生时被指派为男性/女性”（AMAB/AFAB）来表达，但这个词也可能过度强调出生时刻，忽略间性人与后续变化。

顺性别（cisgender）

性别认同与出生时指派性别一致的人。“cis-”是拉丁语“这一侧”，与“trans-”（另一侧）相对。它不是贬义词，也不是“正常”的同义词。

跨性别（transgender）

性别认同与出生时指派性别不一致的人的伞状称呼，包括跨性别女性、跨性别男性、非二元者等。英文中作形容词（a transgender person），不是动词，也一般不用“transgendered”。中文里“跨性别”比“变性人”更被广泛接受。

跨性别女性 / 跨性别男性

跨性别女性：性别认同为女性、出生时被指派为男性的人（常简称 MtF/MTF，但该缩写强调“从男到女”，部分人不喜欢）。跨性别男性：性别认同为男性、出生时被指派为女性的人（FtM/FTM）。

非二元（non-binary / enby）

性别认同不完全属于“男”或“女”的人，可能为性别酷儿、双性别、无性别、性别流动等。非二元者不一定认同为跨性别，也可能使用跨性别作为伞状标签。中文网络中也用“非二元”“NB”“enby”。

性别酷儿（genderqueer）

一种挑战二元性别分类的认同，常带有政治与美学色彩。与“非二元”有重叠，但不是同义词；有人用它表达对性别规范的拒绝，有人用它描述具体的流动经验。

性别流动（genderfluid）

性别认同随时间或情境变化的人。变化可能是缓慢的，也可能是情境性的；不应被理解为“不稳定”或“还没想清楚”。

间性（intersex）

出生时性征（染色体、激素、生殖器）不符合典型男性或女性身体的人。间性是身体差异，不是性别认同；间性者可能是顺性别、跨性别或非二元。不要把“间性”与“跨性别”混用。

双性恋 / 泛性恋 / 多性恋

双性恋：对两个或更多性别有吸引；定义因人而异。泛性恋：对所有性别都可能产生吸引，强调性别不是吸引的门槛。多性恋：对多种性别有吸引。不要用“阶段”“花心”来描述这些身份。

无性恋 / 灰性恋 / 半性恋

无性恋：很少或没有性吸引；不等于没有浪漫情感或不能建立关系。灰性恋：处于有性与无性之间的经验。半性恋：只在建立深层情感联系后产生性吸引。无性恋不是病，也不需要“被治好”。

酷儿（queer）

曾为贬义词，后被部分社群回收，作为对异性恋/顺性别规范的批判性身份。有人视其为包容性伞状词，有人仍因其伤害史而拒绝。使用前注意语境与自称。

Questioning

正在探索自己的性倾向或性别认同的人。探索不需要限期，也不等于“最终一定会变成某个标签”。

性别表达

一个人通过服装、发型、声音、举止、名字与代词等向外呈现性别的方式。性别表达与性别认同不必一致；不应以外表判断一个人的身份。

出柜（coming out）

向他人披露自己的性倾向或性别认同。它是持续的过程，不是一次性事件；有人选择公开，有人选择有限披露，有人因安全原因不出柜。不要替别人出柜。

旧名 / deadname

跨性别者不再使用、与当前身份不符的名字。除法律或医疗必要，不应主动使用或询问；媒体报道应使用本人确认的名字。

代词（pronouns）

指代一个人的词，如“他”“她”“ta”或英文 he/she/they。中文口语中“ta”常作性别中立写法；正式文本可使用“其”或重复名字。询问代词是礼貌的，但不必强迫每个人公开。

passing / 被读作

跨性别者被他人认作其性别认同（而非被识别为跨性别）的状态。“passing”常被视为安全与接纳的指标，但也可能强化“只有像 cis 才算成功”的标准。不是所有跨性别者都追求 passing。

伪装 / 反串 / 变装

“变装”（cross-dressing）指穿着与指派性别规范不同的服装，与性倾向和性别认同无必然关系。“反串”多用于表演。不要用“人妖”“异装癖”等词称呼跨性别者，这些词带有猎奇与病理化色彩。

性别肯定医疗（GAC）

以支持一个人的性别认同为目标的医疗，包括心理支持、激素、手术、声音训练、脱毛等。它不等于“必须做全套”，也不是所有跨性别者都需要医疗。

HRT / GAHT

激素替代治疗（Hormone Replacement Therapy）或性别肯定激素治疗（Gender-Affirming Hormone Therapy）。通过雌激素/抗雄或睾酮改变第二性征。需要监测，部分效果不可逆。

性别不安（gender dysphoria）

与性别不一致相关的显著痛苦或功能受损。它是诊断概念，不是所有跨性别者都有；诊断的存在不应被用来否定没有诊断的人的身份。

易性症 / 性别不一致

中国临床与政策文件中使用的诊断/描述用语。2022 年《性别重置技术临床应用管理规范》使用“易性症（性别焦虑，或性别不一致）”；ICD-11 则用“gender incongruence”。术语变化影响医疗准入与去病理化讨论。

性别重置手术 / 性别肯定手术

中文官方文件常用“性别重置手术”，社群与医学界也使用“性别肯定手术”。包括胸部、生殖器、面部、喉结等不同手术，不是单一项目。不是所有跨性别者都需要或能够接受手术。

青春期阻断剂

用于延缓青春期发育的药物（如 GnRH 类似物），目的是争取时间、减少不可逆的第二性征变化。证据、适应症与可及性在各国存在争议；英国 Cass Review 后政策明显收紧。不可自行使用。

转换治疗 / 扭转治疗

以改变性倾向、性别认同或性别表达为目标的干预，可能包括谈话、电击、药物、羞辱与强制。主要医学组织反对，认为缺乏证据且可能造成伤害。中国无全国禁令，但已有司法赔偿先例。

去过渡（detransition）

停止或逆转部分性别过渡步骤的人。原因多样：社会压力、医疗并发症、身份变化、费用、家庭等。去过渡者的经验应被倾听，但不应被用来否定所有跨性别者的医疗需求。

法定性别承认（LGR）

法律上更改性别标记的程序与制度。模式包括医疗化、专家小组、司法审查与自我声明。联合国人权高专办主张基于自我决定的简易程序，不要求手术、绝育或诊断。

自我决定 / self-ID

申请人以法定声明表示性别认同，经行政程序更改标记，通常不需要医疗证明。不同国家设有年龄、居住期、冷静期或撤销机制。争议集中在未成年人、单性别空间与滥用风险。

意定监护

中国《民法典》中的制度，成年人可预先指定监护人，在丧失或部分丧失民事行为能力时履行监护职责。部分同性伴侣用它安排医疗签字、财产与身后事务，但它不等于婚姻，也不能覆盖所有配偶权利。

平等就业权

劳动者不因性别、性倾向、性别认同等因素在招聘、晋升、待遇与解除合同中被不合理差别对待的权利。中国有多部法律涉及，但“性别认同”是否被明确涵盖仍有司法争议。

仇恨犯罪 / 偏见犯罪

因受害者的真实或被认为的性倾向、性别认同等身份而实施的犯罪。许多国家有加重处罚条款；中国没有专门的仇恨犯罪立法，相关动机可能作为量刑情节。

少数群体压力

因属于被污名群体而承受的额外压力，包括歧视、期待被拒绝、隐藏身份、内化污名与应对偏见。它常被用来解释性少数群体较高的抑郁与焦虑率，而不是把问题归因于身份本身。

交叉性（intersectionality）

1989 年 Kimberlé Crenshaw 提出的概念，强调种族、性别、阶级、残障、性倾向等身份与权力结构的交织。它提醒我们：一个跨性别者也可能同时是残障者、移民、穷人或有色人种，其经验不能被单一身份概括。

TERF

“Trans-Exclusionary Radical Feminist”的缩写，指排斥跨性别女性、认为其不应进入女性空间或获得女性身份的法律承认的部分激进女权主义者。该词带有争议，被批评为标签化；被指称者通常拒绝这一称呼。讨论时应描述具体主张，而不是只贴标签。

“性别批判”（gender-critical）

一种主张生理性别不可改变、反对 self-ID 与部分跨性别权利的立场。支持者认为其在保护女性空间与儿童；批评者认为其重复了污名化与排除。它不是一个统一的学术流派，内部也有分歧。

“西方输入”论

认为 LGBTQ+ 身份与权利话语是西方强加、与本地文化无关的主张。历史研究显示，许多文化有同性欲望与性别多元的记录；同时，现代权利框架确实有特定的西方现代史。两者都需要承认。

Two-Spirit

1990 年由北美原住民社群提出的术语，描述部分原住民文化中的性别与精神角色。它不是“gay”或“trans”的同义词，通常只应由原住民使用；非原住民应避免以此自称。

Hijra

南亚的性别多元社群，有复杂的历史、宗教与社会位置。2014 年印度最高法院承认“第三性别”法律地位；2019 年《跨性别者（权利保护）法》通过。不要把 hijra 简单等同于“跨性别”或“人妖”。

Fa'afafine / Māhū / Bakla 等

太平洋岛屿与东南亚文化中的性别多元角色，各有本地历史与含义。它们不应被直接翻译成“transgender”，也不应被当作旅游奇观。

Pride / 骄傲

起源于纪念石墙事件的游行与纪念活动，现已发展为全球性的可见度与权利倡导。它不是“炫耀”，而是对污名与暴力的回应；不同城市的 Pride 在商业化、警察参与与政治立场上存在争议。

选择的家人（chosen family）

由朋友、伴侣、社群成员组成的支持网络，替代或补充血缘家庭。对许多被原生家庭拒绝的 LGBTQ+ 者而言，它是生存基础设施，而不是“退而求其次”。

没有匹配的词条。试试更短的关键词，或选择“全部”。

使用建议：五个常见问题

“跨性别”和“变性人”有什么区别？

“变性人”在中文里常与手术绑定，带有旧医学与猎奇色彩；“跨性别”更强调性别认同，不要求手术。官方文件仍使用“性别重置手术”等术语，但称呼一个人时，优先使用 ta 的自称。

应该说“LGBTQ 群体”还是“性少数”？

两者都可以，取决于语境。“LGBTQ+”更国际化，“性少数”更中文、更宽泛。正式文本可写“LGBTQ+ 群体（性少数群体）”，首次出现时说明范围。

“ta”是正式写法吗？

在社群与网络语境中常用；正式文件通常仍用“他/她”或“其”。如果你在为一个人写介绍，问 ta 希望用哪个；如果不确定，重复名字或用“其”是安全的。

可以问“你是男是女”吗？

对非二元者，这个问题可能让 ta 被迫进入二元框架。可以问“你希望我用什么代词/称呼”，而不是要求对方归类。对不熟悉的人，直接使用名字最安全。

为什么有些词“过时”得这么快？

语言变化反映社群对尊重与自决的重新协商。一个词可能因为医学化、猎奇化或被反对者使用而失去正当性。没有一成不变的正确词；保持倾听比背词表更重要。
